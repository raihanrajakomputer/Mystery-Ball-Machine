# Mystery Ball

Mini game vending machine berbasis HTML, CSS, dan Vanilla JavaScript.

## Jalankan
Buka `index.html` di browser.

## Fitur
- Login nama
- 1000 poin untuk pemain baru
- Spin 150 poin
- Weighted rarity
- Result message
- Collection
- localStorage
- CSS animation
- Responsive layout

## Reset data
Buka Developer Tools browser > Console, lalu jalankan:
localStorage.removeItem("mysteryBallData");
kemudian refresh halaman.
